> **대상:** 홈페이지 사진을 직접 바꾸는 담당자 (Cursor·코드 불필요)  
> **적용 URL:**  
> - 테스트: https://maxskill-b2b.vercel.app  
> - 실제 도메인 연결 후: https://www.maxskill.co.kr (**방법 동일**)

---

## 1. 이해하기 (3가지만)

1. **수정하는 곳:** GitHub 웹사이트 → **`public/images`** 폴더 안의 **jpg / png 파일**
2. **반영되는 곳:** 메인 슬라이드, 회사소개, **서비스** 페이지 등
3. **건드리지 않는 것:** Cursor, 코드 파일, Vercel 설정

**프로젝트 목록**은 Google **스프레드시트**로 수정합니다. → `프로젝트-시트-관리-매뉴얼.md` 참고.

## 3. 교체 방법 (GitHub 웹)

### ① 저장소 열기

브라우저에서 GitHub → `kimjy0411/maxskill-b2b` 저장소

### ② 이미지 폴더로 이동

| 바꿀 위치 | GitHub 폴더 경로 |
|-----------|------------------|
| 메인 상단 슬라이드 | `public` → `images` → `hero` |
| CEO 사진 | `public` → `images` → `about` |
| 서비스 대표 배너 (4종) | `public` → `images` → `services` |
| 서비스 세부 항목 사진 | `public` → `images` → `services` → `items` |

### ③ 파일 교체

1. 바꿀 **파일 이름**을 클릭 (예: `piping.jpg`)
2. 오른쪽 위 **연필(✏️) Edit** 또는 **Upload files**
3. **같은 이름**의 새 사진으로 교체  
   - ✅ `piping.jpg` → 새 사진도 `piping.jpg`  
   - ❌ `piping-new.jpg` 로 이름 바꾸면 **사이트에 안 바뀜**
4. 아래 **Commit changes** → **Commit to `main`**

### ④ 반영 확인

- **5~10분** 후 사이트 새로고침 (Ctrl+F5)
- Vercel이 GitHub와 연결되어 있으면 **자동 배포**

## 6. 사진 준비 시 주의

| 항목 | 권장 |
|------|------|
| 형식 | jpg (배너·항목), png (CEO 등 투명 배경) |
| 용량 | **1~2MB 이하** (너무 크면 로딩 느림) |
| 가로·세로 | 배너는 **가로로 긴** 사진 (16:9 전후) |
| 파일 이름 | **영문·숫자·하이픈**만 (`piping-plot-plan.jpg`) |

---

## 7. 자주 하는 실수

| 실수 | 결과 |
|------|------|
| 파일 이름을 바꿈 | 사이트 그대로 |
| `main`이 아닌 다른 브랜치에만 commit | 실제 사이트 안 바뀜 |
| 너무 큰 파일 (10MB+) | 업로드 실패 또는 로딩 매우 느림 |
| 코드(`data` 폴더) 수정 | **하지 마세요** — 이미지 폴더만 |

---

## 8. 안 바뀔 때

1. **5~10분** 더 기다리기  
2. 브라우저 **강력 새로고침** (Ctrl + F5)  
3. GitHub에서 commit이 **`main`** 브랜치인지 확인  
4. 파일 **이름**이 목록과 **완전히 같은지** 확인  
5. 그래도 안 되면 관리자에게 Vercel 배포 상태 문의
