# 맥스킬 홈페이지 — 채용 공고 시트 관리

> **대상:** 채용 공고를 올리고 수정하는 담당자  
> **반영 위치:** `/careers` 목록, `/careers/번호` 상세

프로젝트 목록과 같습니다. **시트에 한 줄 = 공고 한 건**입니다.

---

## 1. 공고를 올리는 방법

1. Google 시트 `채용공고` 탭을 연다.
2. **마지막 행 아래**에 새 행을 만든다.
3. 아래 열을 채운다. (1행 헤더는 바꾸지 않는다)
4. 자동 저장된다.
5. **5분** 기다린 뒤 `/careers`를 **Ctrl + F5**로 새로고침한다.

수정은 해당 행만 고치면 됩니다.  
내리려면 **상태**를 `마감`으로 바꾸거나, **접수종료** 날짜를 오늘 이전으로 둡니다.  
삭제는 그 행을 지우면 됩니다.

---

## 2. 열 구성

| 열 | 헤더 | 필수 | 예시 |
|----|------|------|------|
| A | 번호 | ✅ | `4` (기존과 겹치지 않게) |
| B | 공고일자 | ✅ | `2026-03-08` |
| C | 채용명 | ✅ | `배관설계` |
| D | 접수시작 | ✅ | `2026-03-08` |
| E | 접수종료 | ✅ | `2026-12-18` |
| F | 상태 | 선택 | `진행중` / `마감` (비우면 종료일로 자동 판단) |
| G | 조회 | - | 사용 안 함. 열이 있어도 사이트에 나오지 않음 |
| H | 채용구분 | 선택 | 모르면 비움 |
| I | 지원 | 선택 | `경력 우대` |
| J | 학력 | 선택 | `고졸이상` |
| K | 채용분야 | 선택 | `석유화학, 정유, 가스` |
| L | 담당업무 | 선택 | `배관설계` |
| M | 자격요건 | 선택 | `플랜트 배관설계 가능자` |
| N | 채용인원 | 선택 | `2명` |
| O | 공통자격 | 선택 | 한 줄에 하나씩 (`Alt + Enter`) |
| P | 전형방법 | 선택 | `1차 : 서류전형` / `2차 : 면접` |
| Q | 접수방법 | 선택 | 이력서, 이메일 등 |
| R | 기타사항 | 선택 | 희망연봉 기재 |
| S | 담당자 | 선택 | `박경화` |
| T | 부서 | 선택 | `PROJECT T/F` |
| U | 문의전화 | 선택 | |
| V | E-Mail | 선택 | `hanking@maxskill.co.kr` |

여러 줄이 필요한 칸(공통자격, 전형방법, 접수방법, 기타사항)은  
**한 칸 안에 `//` 로 구분**합니다. 엔터로 줄을 바꾸면 행이 쪼개집니다.

예: `1차 : 서류전형 // 2차 : 면접`

샘플 파일: `data/careers-sheet-template.csv`  
(시트에서 **파일 → 가져오기 → CSV** 하면 열 제목이 그대로 들어갑니다.)

## 3. 처음 1회 — 같은 시트에 탭 만들기

**문서:** [맥스킬_프로젝트_수행실적](https://docs.google.com/spreadsheets/d/14oLvGSSTKnWrInzze6b3t38ksQZ9vbH7oF6y57SCkdw/edit)

1. 위 링크를 연다. (프로젝트 탭이 있는 그 문서)
2. 왼쪽 아래 **+** 로 탭을 추가하고 이름을 `채용공고`로 바꾼다.
3. 1행에 아래 헤더를 그대로 붙여 넣는다.

```
번호	공고일자	채용명	접수시작	접수종료	상태	조회	채용구분	지원	학력	채용분야	담당업무	자격요건	채용인원	공통자격	전형방법	접수방법	기타사항	담당자	부서	문의전화	E-Mail
```

4. 2행부터 공고를 적거나, `data/careers-sheet-template.csv`를 **파일 → 가져오기** 한다.
5. **파일 → 공유 → 웹에 게시**
   - 왼쪽: `채용공고` 탭
   - 오른쪽: **쉼표로 구분된 값(.csv)**
   - **게시**
6. `채용공고` 탭은 연결됨 (`gid=1559697366`).

프로젝트 탭(`맥스킬_프로젝트_수행실적`)은 그대로 두고, **채용은 `채용공고` 탭만** 고치면 됩니다.
