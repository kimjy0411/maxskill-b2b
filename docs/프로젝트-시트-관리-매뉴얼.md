# 맥스킬 홈페이지 — 프로젝트 목록 관리 매뉴얼 (정식)

> **대상:** 프로젝트 목록을 직접 수정하는 담당자 (비개발자)  
> **적용 URL:**  
> - 테스트: https://maxskill-b2b.vercel.app/projects  
> - 실제 도메인 연결 후: https://www.maxskill.co.kr/projects (**방법 동일**)

---

## 1. 이해하기 (3가지만)

1. **수정하는 곳:** Google **스프레드시트** (엑셀처럼, 웹 브라우저)
2. **반영되는 곳:** 홈페이지 **프로젝트** 페이지
3. **건드리지 않는 것:** Cursor, GitHub, Vercel, 코드

**도메인을 실제 회사 주소로 바꿔도, 시트에서 고치는 방법은 똑같습니다.**

| 항목 | 내용 |

## 3. 표 구조 (1행 = 제목, 2행~ = 데이터)

**열 순서와 1행 헤더는 바꾸지 마세요.**

| 열 | 1행 헤더 | 입력 예시 | 필수 |
|----|----------|-----------|------|
| **A** | 프로젝트 | `카타르 LNG NFXP EPC.2 Project` | ✅ |
| **B** | 원도급사 | `삼성물산(주)` | ✅ |
| **C** | 분야 | `화공` / `발전` / `LNG` | ✅ |
| **D** | Year | `2026` | ✅ |
| **E** | Location | `Korea`, `Qatar` | ✅ |
| **F** | Service | `D,M,S` (없으면 `-`) | 선택 |
| **G** | Tool | `PDS`, `E3D` | 선택 |

### C열 「분야」 — 아래 **정확히** 하나만

```
화공
발전
LNG
```

- `화공 ` (뒤 공백), `lng`, `LNG Plant` 등 → **사이트에 안 나옴**

### F열 Service 코드

| 코드 | 의미 |
|------|------|
| M | Modeling |
| D | Design |
| S | Stress |
| C | Construction Supervisor |

예: `D,M,S` / `D,M` / 없으면 `-`

## 4. 일상 작업 — 프로젝트 **추가**

1. Google 시트를 연다.
2. **데이터가 있는 마지막 행 바로 아래** 빈 행을 클릭한다.
3. **A → B → C → D → E → F → G** 순서로 입력한다.
4. 입력이 끝나면 **저장** (Google 시트는 자동 저장됨).
5. **5분** 기다린다.
6. 브라우저에서 프로젝트 페이지를 연다 → **Ctrl + F5** (강력 새로고침).
7. 아래를 확인한다.
   - 새 프로젝트가 **해당 분야 표**(화공/발전/LNG)에 있는지
   - 상단 **총 프로젝트 / 화공 / 발전 / LNG** 숫자가 **1 증가**했는지
   - 목록 제목 옆 **「· Google Sheet 연동」** 이 보이는지

---

## 5. 일상 작업 — 프로젝트 **수정**

1. 고칠 **행**을 찾는다.
2. 해당 **셀만** 수정한다 (예: Location, Year).
3. 저장 → **5분 대기** → **Ctrl + F5** 새로고침.

---

## 6. 일상 작업 — 프로젝트 **삭제**

1. 삭제할 **행 번호** 왼쪽(행 번호)을 클릭해 **행 전체** 선택.
2. 우클릭 → **행 삭제**.
3. 저장 → **5분 대기** → **Ctrl + F5** 새로고침.
4. 상단 **총 개수**가 **1 감소**했는지 확인.

---

## 7. 숫자(총 55건 등)는 어떻게 맞춰지나

- **총 프로젝트 / 화공 / 발전 / LNG** → 시트 **유효한 행**만 세서 **자동** 표시
- 담당자가 숫자를 따로 적을 필요 **없음**
- 시트에 **55행** 데이터 + 모두 유효 → 사이트 **총 55**
- **1행이라도 유효하지 않으면** 그 행은 **빠지고**, 총 개수도 **그만큼 적게** 보임

### 「유효하지 않다」는 뜻 (이 행은 사이트에 **안 나옴**)

| 원인 | 예시 |
|------|------|
| 분야(C) 오타 | `lng`, `화학`, 빈칸 |
| 연도(D) 숫자 아님 | `2026년`, 빈칸 |
| 프로젝트명(A) 비어 있음 | 빈칸 |
| **프로젝트명에 쉼표(,)** | `70,000MT/Y` → 칸이 밀려서 전체 행 오류 |

**실제 사례:**  
`여수 금호폴리켐 70,000MT/Y …` → 쉼표 때문에 **1건 빠져 54건**으로 보였음  
→ `70000MT/Y` 로 고치면 **55건**으로 복구

## 8. 입력 후 스스로 점검 (30초)

한 행을 입력·수정한 뒤, **각 값이 올바른 열**에 들어갔는지 확인:

```
A: 프로젝트명만  |  B: 원도급사만  |  C: 화공/발전/LNG만
D: 연도 숫자만  |  E: Location  |  F: Service  |  G: Tool
```

**한 셀에 두 정보가 섞여 있거나**, C열에 회사명이 들어가 있으면 → **행 전체를 지우고 다시 입력**.

## 9. 꼭 지킬 것 / 하지 말 것

### ✅ 지킬 것

- **Google 스프레드시트(웹)** 에서만 수정
- 분야는 `화공` / `발전` / `LNG` 만
- 프로젝트명·원도급사에 **쉼표(,) 사용 금지** → `70000` / `70.000` 사용
- 수정 후 **5분 + Ctrl+F5**

### ❌ 하지 말 것

- PC **엑셀(.xlsx) 파일**만 수정 (사이트와 연결 안 됨)
- **1행 헤더** 삭제·이름 변경
- **A~G 열 순서** 바꾸기
- 테스트용 `d`, `test` 행 **공개 전 삭제 안 하기**
- Vercel / GitHub / 코드 직접 수정

## 14. FAQ

**Q. 행을 추가했는데 개수가 안 늘어요.**  
A. C열 분야·D열 연도·쉼표 오류 확인 → 8절 점검 → 5분 후 Ctrl+F5.

**Q. 1개 추가했는데 총 개수가 그대로예요.**  
A. 다른 행 1개가 **유효하지 않아** 빠진 경우. 시트 전체 행을 8절 기준으로 점검.

**Q. Cursor가 꼭 필요해요?**  
A. 아니요. **시트만** 수정하면 됩니다.

**Q. 회사소개·인원·채용도 시트로 고치나요?**  
A. 채용 공고는 시트 연동이 가능합니다. 환경변수 `GOOGLE_SHEETS_CAREERS_CSV_URL`을 연결하면 시트에서 공고를 올리고, 사이트 채용명 클릭 시 상세 페이지로 이동합니다. 열: 번호, 공고일자, 채용명, 접수시작, 접수종료, 상태, 내용.
